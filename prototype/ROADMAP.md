# 神经免疫 · 产品路线图

> 从「架构原型」到「产品」的差距不在字段映射、置信度这类参数，而在**定位与楔子**。
> 本文件记录产品视角的重定位，以及未来可视化计划。

## 一、重定位：三个产品决策

### 1. 卖「省人力」，不卖「省算力」

「告警降噪」在工程上漂亮，但买方（三千人制造企业、五个安全人）痛的是**人看不过来**，
不是 GPU 账单。口号从"贵模型只醒 2 次"换成"**你的五个人像二十个人用**"。
架构不动，卖法换。

### 2. 「抑制」改「排序 + 留痕」，不是「静默」

安全团队的饭碗是"不漏"（漏报），不是"不吵"（误报）。"AI 自动压掉告警"是信任杀手。
所以：被抑制的信号**不丢弃，降级留痕、全程可审计**——已实现（`suppressed_log` →
`last_run.json.suppressed` → 观测页「被抑制的信号 · 可审计」）。对外讲法是
"排到最后、盖上为什么，不是不给你看"。

### 3. 楔子是一个集成，不是六层

最小可卖 = 「接你的 SIEM/EDR → 便宜模型降噪 → 每天只顶给你真正要看的 N 条」。
六层大脑是愿景，不是第一天要交付的东西。买家先选 **MSSP**（告警疲劳最重、毛利最薄、
最愿为降噪付费），不是制造企业。

## 二、未来可视化计划

观测页（`report.html`）目前覆盖「降噪 / 越用越准 / 风险档位」的批处理快照。往产品化走，可视化要补这几件：

| 优先级 | 事项 | 为什么 |
|---|---|---|
| P0 | **黑板实时视图**（receiver 流式刷新） | 现在黑板只在批处理 `last_run.json` 里快照；接 24h syslog 后要能看到「全局工作空间」上信号实时竞争、拼链成形 |
| P0 | **被抑制信号审计面板** | 已完成静态版；实时版要让分析师能点开每条"为什么被压"、一键"误压，放回"（喂回免疫耐受） |
| P1 | **旋钮切换器** | 页面上直接拨「宽松/正常/保守/战时」，看漏斗、顶出名单、预算实时变 |
| P1 | **置信度校准视图** | 把模型置信度分布画出来（我们实测过"正常登录判 0.95"的错位），帮调 0.55/0.75 阈值 |
| P2 | **决策可解释** | 每条顶出：为什么 conf + 关联加成越过线、是哪几条弱信号拼的链——点击展开 |
| P2 | **多租户/跨天记忆视图** | 免疫记忆随天数累积的"越用越省"曲线（省了多少次模型调用 / 误报率下降） |

**实现约束**：继续走"Python 生成自包含静态 HTML"，不起 Web 服务、不引前端框架——
贴合"最小、离线、不沾大屏"。receiver 实时视图若需要，用 SSE 或轮询 JSON 落盘文件，而不是起个完整后端。

## 三、暂缓（诚实标记）

- **置信度校准**：命门，但按用户要求暂缓——上线前必须做，不是可选项。
- **多租户共享情报 / 向量记忆**：护城河级别的后话，等楔子跑出 NRR 再说。

## 四、开发待办

- ~~**批量 `process()` 对齐**~~：已解决——CLI `ingest.py` 与文件上传模块已废除，批量 `process()` 随之移除，只留流式 `process_signal`（自带 budget + 单信号门槛）。
- **案件实体图链式视图**（可选）：案件详情现在是「同告警内实体两两连线」的共现图，可改成按攻击阶段时序的 kill-chain 视图（合并 IP↔主机对、按时间排序）。
- **免疫签名相似度匹配**（可选进阶）：现在免疫层按签名精确相等匹配，将来可用 Jaccard / SimHash 或 embedding 余弦相似度做「近似去重」，把相似但不完全相同的告警聚成一簇（Drain + 语义相似度做告警降噪的论文报告了 >99% 噪声削减）。
- **免疫签名掩码粒度可配**：`signature.py` 目前掩码 IP / 哈希 / 独立数字、保留主机名 / 账号——这个「什么算变量」的边界可以做成设置项（进 `state` + 设置页，跟阈值收敛同套路）。
